# interview

The questions of stop 2, in this order. Ask one at a time with AskUserQuestion, the recommended answer first. Skip a question the material or the request already answers.

| # | Question | Recommended answer |
|---|---|---|
| 1 | What is the skill called? | a verb and its object, kebab-case: `write-investor-update` |
| 2 | Does the process change with the situation, so that some runs look for different things? | no: one situation, no `variants/` |
| 3 | Where does the output go, and in what shape? | a dated file in a folder named after the output, the shape of the best manual run |
| 4 | What must the skill have to start, and what helps but is optional? | the input every manual run started from is required, the rest recommended |
| 5 | Which tools or connectors does it call? | the ones the manual runs called, none otherwise |
| 6 | Which steps give the same result every time? | dates, paths, counts, sums and format checks become scripts |
| 7 | Who uses it? | `personal`, until the team runs it too |
